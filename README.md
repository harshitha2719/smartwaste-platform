\# SmartWaste Platform



An IoT-enabled smart waste segregation and reward platform combining:



\- Computer vision

\- ResNet50-based waste classification

\- ESP32 / ESP32-CAM

\- Embedded sensors

\- Automated waste segregation

\- User rewards

\- Web-based waste management

\- PostgreSQL

\- Power BI analytics



\## Project Status



Software development in progress.



The hardware integration will initially be represented using a simulated ESP32 data source. The simulator will later be replaced by the physical ESP32/ESP32-CAM system.
